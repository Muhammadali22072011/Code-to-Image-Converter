# 🚀 Быстрый старт - Code to Image Converter

## 📋 Что я создал для вас

✅ **Полнофункциональное веб-приложение** для создания красивых изображений из кода
✅ **Современный дизайн** с красивыми анимациями и градиентами  
✅ **Темная/светлая тема** с автоматическим переключением
✅ **20+ языков программирования** с подсветкой синтаксиса
✅ **10+ тем оформления** (Dracula, Monokai, VS Code и др.)
✅ **Экспорт в PNG, JPEG, WebP, SVG** с настраиваемым качеством
✅ **PWA поддержка** - работает как приложение и офлайн
✅ **Полная адаптивность** для всех устройств

## 🌐 Как запустить

### Вариант 1: Простой запуск (уже работает!)
Откройте браузер и перейдите по адресу: **http://localhost:8000**

### Вариант 2: Если нужно перезапустить
```bash
python -m http.server 8000
```

## 🎯 Основные возможности

### 🎨 Создание изображений
1. **Введите код** в левый редактор
2. **Выберите язык** (JavaScript, Python, Java, C++ и др.)
3. **Настройте тему** (Dracula, Monokai, VS Code и др.)
4. **Выберите фон** (10 красивых градиентов)
5. **Скачайте или скопируйте** результат

### ⚙️ Расширенные настройки
- **Размер изображения**: настраиваемая ширина/высота
- **Качество**: от 80% до 100%
- **Шрифты**: JetBrains Mono, Fira Code, Source Code Pro
- **Размер шрифта**: от 12px до 32px
- **Опции**: номера строк, рамка окна, тени

### 🔥 Горячие клавиши
- `Ctrl+S` - Скачать изображение
- `Ctrl+C` - Копировать в буфер обмена (вне поля ввода)
- `Ctrl+Shift+F` - Форматировать код
- `Ctrl+Shift+C` - Очистить код
- `Escape` - Закрыть модальные окна

### Не загружается страница?
- Убедитесь, что сервер запущен на порту 8000
- Проверьте, что нет других процессов на этом порту

### Не работает копирование в буфер?
- Современные браузеры требуют HTTPS для копирования изображений
- Локально работает копирование текста

### Медленно генерируется изображение?
- Уменьшите размер изображения в настройках
- Снизьте качество до 80-90%
